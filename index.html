How the recursive algorithm works

STEP 01
Move n − 1 disks

Move the smaller stack from the source rod to the auxiliary rod.

STEP 02
Move the largest disk

Move the remaining largest disk from the source rod to the destination.

STEP 03
Complete the stack

Move the smaller stack from the auxiliary rod onto the destination rod.

Algorithm analysis

T(n) = 2n − 1
Time complexity: O(2n) because each extra disk roughly doubles the number of moves.
Auxiliary space: O(n) for the recursion call stack.
Goal: Transfer all disks from A to C in the minimum number of moves.
